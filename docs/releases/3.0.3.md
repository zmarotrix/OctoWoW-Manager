### 🐧🍎 Linux and macOS: easier Wine and Proton setup
**Play** runs `VanillaFixes.exe WoW_Tweaked.exe` through your Wine command, so VanillaFixes loads your DLLs and starts the tweaked client. You don't need to rename anything.

The **Wine command** box (Game Settings → Installation) now accepts more:

* **A Proton folder**, e.g. `~/.local/share/Steam/compatibilitytools.d/GE-Proton11-11`. If `umu-run` is installed it's used, as Faugus does. Otherwise Proton is started directly. Choosing a folder no longer fails with "No permission (os error 13)".
* **A Wine folder** (one with `bin/wine` inside, like Lutris runners).
* **`VAR=value` settings first**, e.g. `WINEPREFIX=~/Games/wow wine` or `WINEPREFIX=~/Games/umu/wow ~/.local/share/Steam/compatibilitytools.d/GE-Proton11-11`.
* **Quoted paths with spaces**, e.g. `"/opt/wine builds/bin/wine"`.
* A wrapper script still works the same way. It receives `VanillaFixes.exe WoW_Tweaked.exe` as its arguments.

**Fixed:** the Linux AppImage passed its own library and Python paths to the game, which could break Proton. These are now removed before the game starts, so wrapper scripts no longer need `unset LD_LIBRARY_PATH ...`.

### 📥 Downloads
Each download is a single standalone program with everything built in. There's no installer.

| Platform | File |
|---|---|
| Windows 10/11 | `OctoWoW_Manager_v3.0.3_windows_x64.exe`: just run it |
| Linux (x64) | `OctoWoW_Manager_v3.0.3_linux_x64.AppImage`: `chmod +x` it, then run |
| macOS (Intel + Apple Silicon) | `OctoWoW_Manager_v3.0.3_macos_universal.zip`: unzip, then right-click → **Open** the first time |

> **Antivirus / SmartScreen:** builds aren't code-signed yet, so Windows may warn about an unrecognized app. Click **More info → Run anyway**. All source code is in this repository, and every build is produced by GitHub Actions from it.
