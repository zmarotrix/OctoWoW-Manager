### 🐛 Fix: "World of Warcraft was unable to start up 3D acceleration"
3.0.0 always installed a DXVK renderer, including on PCs whose graphics driver can't run it, which produced this error at launch.

* **New DXVK choices** in Game Settings → Environment:
  * **Standard DXVK (NVIDIA/Intel):** DXVK 2.6.1
  * **AMD Specific DXVK:** DXVK 2.5.3
  * **Older GPUs:** DXVK 1.10.3, for drivers without Vulkan 1.3
  * **Off (DirectX 9):** no DXVK. The game uses Windows' own DirectX 9, and `d3d9.dll` is set aside as `d3d9.dll.off`.
* **Automatic safety check:** Apply Changes now checks your graphics driver first. With no Vulkan support it uses DirectX 9; with Vulkan older than 1.3 it uses the Older GPUs build. It tells you when it does this.
* Game Settings shows your detected graphics card and Vulkan version.
* The Standard and AMD DXVK builds are now built into the manager, so nothing is downloaded when you apply.

**Already hit the error?** Update to 3.0.1 and click **Apply Changes**. Or, without updating, rename `d3d9.dll` in your game folder to `d3d9.dll.off`.

### 🐧🍎 Linux and macOS builds
OctoWoW Manager now runs on Linux and macOS too. The game itself runs through Wine (or CrossOver on Mac); set the command under Game Settings → Installation.

### 📥 Downloads
Each download is a single standalone program with everything built in. There's no installer.

| Platform | File |
|---|---|
| Windows 10/11 | `OctoWoW_Manager_v3.0.1_windows_x64.exe`: just run it |
| Linux (x64) | `OctoWoW_Manager_v3.0.1_linux_x64.AppImage`: `chmod +x` it, then run |
| macOS (Intel + Apple Silicon) | `OctoWoW_Manager_v3.0.1_macos_universal.zip`: unzip, then right-click → **Open** the first time |

Coming from the old OctoWoW Installation Manager (v2.6)? Use **Game Settings → Import v2.6 settings** and pick your old `octowow_config.json`.

> **Antivirus / SmartScreen:** builds aren't code-signed yet, so Windows may warn about an unrecognized app. Click **More info → Run anyway**. All source code is in this repository, and every build is produced by GitHub Actions from it.
