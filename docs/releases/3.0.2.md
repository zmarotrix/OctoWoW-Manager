### 🧩 Addons: any git repository, and GitAddonsManager
* **Install from any git URL.** The manager now has a built-in git client, so repositories on hosts without zip downloads work too. You still don't need git installed.
* **octowow.st/git links work.** Paste a link from the OctoWoW git site and it installs normally.
* **Git checkouts update in place.** Addons installed by the OctoLauncher or **GitAddonsManager** are updated with git, keeping the `.git` folder. Anything you added to the folder yourself stays.
* **GitAddonsManager's multi-addon repos are recognised.** Repos that hold several addons (kept as `<Name>.repo`, with each addon moved into AddOns) appear as their separate addons. They update together, and the `.repo` folder is removed along with the last of its addons.
* **Choose what to update.** Untick addons in **Updates Available** to leave them out, then click **Update Selected**.
* **Ignore updates for an addon.** Use the bell button on an addon to hide its updates until you turn them back on.

### 🎮 Game
* **Run several copies of WoW at once.** Play no longer refuses to start while the game is already running.
* **UnitXP "Latest"** now downloads from [brues-code/UnitXP_SP3](https://github.com/brues-code/UnitXP_SP3), with credit shown in Client Tweaks. **Recommended** still installs the copy built into the manager.

### 📥 Downloads
Each download is a single standalone program with everything built in. There's no installer.

| Platform | File |
|---|---|
| Windows 10/11 | `OctoWoW_Manager_v3.0.2_windows_x64.exe`: just run it |
| Linux (x64) | `OctoWoW_Manager_v3.0.2_linux_x64.AppImage`: `chmod +x` it, then run |
| macOS (Intel + Apple Silicon) | `OctoWoW_Manager_v3.0.2_macos_universal.zip`: unzip, then right-click → **Open** the first time |

> **Antivirus / SmartScreen:** builds aren't code-signed yet, so Windows may warn about an unrecognized app. Click **More info → Run anyway**. All source code is in this repository, and every build is produced by GitHub Actions from it.
